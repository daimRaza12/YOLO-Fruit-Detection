
# YOLO Fruit Detection System

## Project Description
A multi-class fruit detection application using YOLOv8n.

## Fruit Classes
- Apple
- Banana
- Grape
- Orange
- Pineapple
- Watermelon

## Technologies
- Python
- YOLOv8
- Ultralytics
- OpenCV
- Streamlit
- Google Colab

## Features
- Upload images
- Adjustable confidence threshold
- Fruit detection with bounding boxes
- Display fruit names
- Display confidence scores
- Total detected objects

## Installation

pip install -r requirements.txt

## Run Application

streamlit run app.py
